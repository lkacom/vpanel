<p dir="rtl" align="right">
<strong>VPanel</strong> یک پنل مدیریتی مدرن و حرفه‌ای با رابط کاربری ساده و تجربه کاربری روان است که برای مدیریت کاربران و سرویس‌های مختلف پنل‌های <strong>x-ui</strong> طراحی شده است. این پنل امکاناتی مانند ساخت، حذف و تمدید کاربران را در اختیار مدیران قرار می‌دهد.

در طراحی VPanel تلاش شده است فرآیند مدیریت کاربران، سرویس‌ها و حسابداری فروش، بدون نیاز به دانش فنی گسترده و با رویکردی ساده و کاربردی انجام شود؛ به‌گونه‌ای که مدیران وب‌سایت‌ها و ارائه‌دهندگان سرویس‌های VPN بتوانند به‌راحتی سرویس‌های خود را مدیریت کنند.
</p>
<p align="center">

** این پروژه بر روی هاست اشتراکی هم قابل نصب است به شرطی که فایروال سرور میزبان، درخواست های API از سرور V2Ray شما را مسدود نکند.**
</p>

<h2 dir="rtl">🆕 تغییرات و امکانات جدید در VPanel</h2>

* طراحی مدرن و رابط کاربری جذاب‌تر 
* تاریخ شمسی پنل در بخش کاربران
* همگام سازی خودکار بدون نیاز به اضافه کردن دستی ورودی یا اینباند
* راه اندازی اولیه فقط با تکمیل یک فرم
* فعال سازی بخش تمدید و تحویل آنی اکانت به صورت خودکار
* عدم نیاز به رفرش برای انتخاب ورودی پیش فرض
* بهبود منو کاربری داشبورد مدیریت 
* امکان جدید 'تاریخچه تراکنشها' و قابلیت جستجو و فیلتر 
*  نمودار 30 روزه فروش
* قابلیت فعال سازی لینک سابسکریپشن
*  ویرایش فرم ها به صورت آجاکس
* بهینه‌سازی عملکرد و امنیت پنل
* تغییرات ظاهری  دکمه های جداول و فرمها
* رفع مشکلات امنیتی axios  برای جلوگیری حملات DDos

امکانات دیگر در دست طراحی است و به زودی به VPanel  اضافه خواهد شد که با بروزرسانی آن را دریافت خواهید کرد.

## 🛠️ تکنولوژی‌های استفاده شده

* **فریم‌ورک:** Laravel 13
* **پنل مدیریت:** Filament 5
* **زبان:** PHP 8.3+
* **وب سرور:** Nginx
* **دیتابیس:** MySQL

## ⚙️ نصب سریع

### پیش‌نیازها

* سرور با Ubuntu 22.04
* دامنه یا زیردامنه متصل به IP سرور
* دسترسی SSH با کاربر root یا sudo
* MySQL 8.0 یا بالاتر

### دستور نصب

```bash
wget -O install.sh https://raw.githubusercontent.com/lkacom/vpanel/main/install.sh && sudo bash install.sh
```

### مشخصات پیش فرض ورود

نام کاربری: admin@example.com
رمز عبور: admin

پس از اولین ورود فورا" رمز عبور خود را تغییر دهید.
